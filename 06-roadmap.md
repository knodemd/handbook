# 6 - Roadmap

Where Knode is and what comes next. Each version is a milestone in the repositories it touches;
what goes into each one is decided in its issues, in the open.

| Version | What | Status |
|---|---|---|
| **Foundation** | Brand kit, handbook, licences, knode.md | Done |
| **v0.1** | The `.knode` format v0, the Rust core, Knode Service and the MCP server (search, read, write, link), capture from Claude Code and Codex, and a first Mac app: open a space, list, note and search | Next |
| **v0.2** | Several spaces, folders per space, capture on or off per project, permissions per agent, every agent, Markdown in both directions | Planned |
| **v0.3** | Graph and canvas, importers (web chats, notes, reading), local semantic search, editing at the same time | Planned |
| **v0.4** | Sync: iCloud for free and Knode Cloud, end-to-end encrypted. The iPhone and iPad app | Planned |
| **v0.5** | Collaboration: share by link, shared spaces and team spaces | Planned |
| **v1.0** | Everything above, polished. The format specification published, documentation at knode.md/developers | Planned |

Plugins are not part of v1.0.
