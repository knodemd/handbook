# 6 - Roadmap

Where Knode is and what comes next. Dates are left out on purpose; order matters more.
Each phase is a milestone in the repositories it touches.

| Phase | What | Status |
|---|---|---|
| **Foundation** | Brand kit, handbook, organisation profile | In progress |
| **Format** | The `.knode` specification: an open, documented file anyone can read and write | Next |
| **App, first version** | Native macOS app: open and save `.knode` maps, explore nodes and links | Planned |
| **Import** | Turn ChatGPT and Claude exports, and notes, into nodes | Planned |
| **iOS** | The map on iPhone and iPad | Planned |
| **Developers** | CLI, local API and MCP server around the `.knode` format | Planned |

What exactly goes into each phase is decided in its issues, in the open.
