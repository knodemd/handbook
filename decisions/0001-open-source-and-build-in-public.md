# 0001 · Open source and built in public from day one

**Status:** accepted · 2026-10-19

## Context

Knode asks people to trust it with their thoughts. That trust is easier to earn when everything
can be inspected: the code, the file format, and how decisions are made.

## Decision

Knode is fully open source and built in public. Every repository in the `knodemd` organisation is
public from its first commit, with a licence, a README and the shared community files.

## Consequences

- No secrets or personal data ever go into a repository (see *Building in public*).
- Work is planned and discussed in public issues; decisions are written down here.
- Forks are welcome; the name and logo are protected by the trademark policy, not by secrecy.
